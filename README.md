# MrYum Cafe

A responsive cafe storefront prototype built with HTML, CSS, and vanilla JavaScript. It explores a menu-focused shopping experience without a framework.

## Highlights

- Product cards, search, and a client-side cart interface.
- Mobile navigation and accessible overlays with keyboard focus management.
- Responsive layouts for browsing on phones and larger screens.

## Run locally

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Scope

The cart is a front-end interaction. This repository does not contain a payment processor or order back end.
